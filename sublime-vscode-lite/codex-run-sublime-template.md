# Codex Run Template

Paste this into Codex's run box to open the current workspace in Sublime Text:

```bat
D:\app\.codex\project\open-in-sublime.cmd
```

Use this to open a specific project:

```bat
D:\app\.codex\project\open-in-sublime.cmd D:\app\.codex\project\BSA
```

Use this to open a specific file:

```bat
D:\app\.codex\project\open-in-sublime.cmd D:\app\.codex\project\BSA\ploidy30_bsa_bundle_20260318\README.md
```
